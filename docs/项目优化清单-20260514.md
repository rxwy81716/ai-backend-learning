### 4. [性能] RerankService 添加超时+重试+熔断

**位置**: `src/main/java/com/jianbo/localaiknowledge/service/RerankService.java`

**问题**: 2000ms 超时无重试，偶发网络抖动直接失败

```java
// 1. 增加超时时间
@Value("${app.rag.rerank.timeout-ms:5000}")
private long timeoutMs;

// 2. 添加重试机制
private String rerankWithRetry(List<SearchResult> candidates) {
    int maxRetries = 2;
    for (int i = 0; i < maxRetries; i++) {
        try {
            return doRerank(candidates);
        } catch (Exception e) {
            if (i == maxRetries - 1) throw e;
            log.warn("Rerank 失败，重试第 {} 次", i + 1);
        }
    }
    return candidates; // 兜底返回原始顺序
}
```

### 12. [架构] KnowledgeAgent 三级嵌套检索重构

**位置**: `src/main/java/com/jianbo/localaiknowledge/service/agent/KnowledgeAgent.java`

```java
// 当前：3 层嵌套 if-else
// 建议：策略链模式

public interface RetrievalStrategy {
    Flux<String> search(String query, int topK);
    boolean shouldRetry(String query, List<?> lastResult);
}

public class PreciseRetrievalStrategy implements RetrievalStrategy { ... }
public class RetryAfterCleaningStrategy implements RetrievalStrategy { ... }
public class BroadRetrievalStrategy implements RetrievalStrategy { ... }

public class RetrievalStrategyChain {
    private final List<RetrievalStrategy> strategies;
    
    public Flux<String> execute(String query) {
        for (RetrievalStrategy s : strategies) {
            var result = s.search(query, topK);
            if (s.shouldRetry(query, result)) continue;
            return result;
        }
        return Flux.empty();
    }
}
```
