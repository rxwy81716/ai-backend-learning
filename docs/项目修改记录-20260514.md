## 二、修改文件

### 1. SysUserMapper.java
**修改内容：** 修复 N+1 查询

- 新增 `findAllWithRoles()` 方法，使用 `LEFT JOIN` 一次性获取用户+角色
- 替代原来的 `findAll()` + 多次 `findRolesByUserId()` 调用

```sql
SELECT u.id, u.username, u.nickname, u.email, u.phone, u.avatar, u.enabled,
       u.created_at, u.updated_at,
       r.id as role_id, r.code as role_code, r.name as role_name
FROM sys_user u
LEFT JOIN sys_user_role ur ON u.id = ur.user_id
LEFT JOIN sys_role r ON ur.role_id = r.id
ORDER BY u.id, r.id
```

### 2. UserService.java
**修改内容：** 登录失败限制（账户锁定）— **已改为 Redis 实现**

**实现方式：**
- 使用 Redis String 结构存储失败次数（`account:failed:{username}`）
- 使用 Redis String 结构存储锁定截止时间（`account:lock:{username}`）
- 失败次数 key 设置 TTL 为 `lockDurationMinutes * 2`，自动清理
- 5 次失败后锁定 30 分钟

**Redis Key 设计：**
- `account:failed:{username}` — 失败次数计数
- `account:lock:{username}` — 锁定截止时间戳

```java
private static final String FAILED_KEY_PREFIX = "account:failed:";
private static final String LOCK_KEY_PREFIX = "account:lock:";

private void recordFailedAttempt(String username) {
    String failedKey = FAILED_KEY_PREFIX + username;
    Long count = redisTemplate.opsForValue().increment(failedKey);
    // 设置过期时间（防止数据残留）
    redisTemplate.expire(failedKey, lockDurationMinutes * 2L, TimeUnit.MINUTES);
    
    if (count >= maxFailedAttempts) {
        long lockUntilMs = System.currentTimeMillis() + lockDurationMinutes * 60 * 1000L;
        redisTemplate.opsForValue().set(LOCK_KEY_PREFIX + username, String.valueOf(lockUntilMs));
        redisTemplate.delete(failedKey); // 锁定后清除失败次数
    }
}
```

### 3. KnowledgeAgent.java
**修改内容：** 重构为策略链模式

将三级嵌套 if-else 检索逻辑重构为 `RetrievalStrategy` 接口的策略链模式，包含 4 个策略：
- `PreciseRetrievalStrategy` — 精确检索
- `FirstRetrievalReuseStrategy` — 首轮复用
- `StripMetaRetryStrategy` — 去元词重试
